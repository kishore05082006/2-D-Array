# Java 2D Array & Matrix Practice

A collection of Java solutions for basic 2D array (matrix) problems, including LeetCode questions. Each program reads input from the console using `Scanner`.

## Problems

| # | Problem | LeetCode | File | Approach |
|---|---------|----------|------|----------|
| 1 | Read and Print a 2D Array | – | `Readandprinta2Darray.java` | Nested loops to read and print row by row |
| 2 | Richest Customer Wealth | [1672](https://leetcode.com/problems/richest-customer-wealth/) | `Richestcustomerwealth-maxrowsum_LC_1672_.java` | Find the maximum row sum |
| 3 | Matrix Diagonal Sum | [1572](https://leetcode.com/problems/matrix-diagonal-sum/) | `Sumofmatrixdiagonals_LC_1572_.java` | Add elements where `i == j` or `i + j == n - 1` |
| 4 | Check if Matrix Is X-Matrix | [2319](https://leetcode.com/problems/check-if-matrix-is-x-matrix/) | `CheckifmatrixisX-Matrix_LC_2319_.java` | Diagonal elements must be non-zero, all others zero |
| 5 | Toeplitz Matrix | [766](https://leetcode.com/problems/toeplitz-matrix/) | `Toeplitzmatrix_LC_766_.java` | Check `a[i][j] == a[i+1][j+1]` |
| 6 | Transpose Matrix | [867](https://leetcode.com/problems/transpose-matrix/) | `Transposeofamatrix_LC_867_.java` | Create a `c x r` matrix and set `b[j][i] = a[i][j]` |
